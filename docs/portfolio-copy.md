## Introduction

I like building useful software. I work mostly with Go, developing backend services and tools for Linux. I enjoy understanding how things work and turning that understanding into software that solves practical problems.



## ClipDeck

Your clipboard, with a memory. A clipboard manager for Linux that keeps what you copy searchable and within reach, with persistent history and a keyboard-first workflow.



## Whisper Social

A social backend that processes timeline updates in the background using Redis Streams, keeping post creation separate from the work of updating followers’ feeds.



## AetherDB

A key-value store where I explore how storage works, from memory-mapped files and concurrent indexing to zero-copy reads with sendfile.



## Argus

A self-hosted monitoring tool for websites and services, with availability, keyword, heartbeat, and TLS checks to help track failures and incidents.



## SysKit

A read-only terminal tool for exploring Linux system information. It reads from /proc, /sys, and Netlink directly, without relying on external shell commands.



## Understand the problem.

I like figuring out how things work before changing them. Reading the code and tracing the behavior help me choose what to build or fix.



## Make deliberate choices.

## Learn through building.

These projects are a way to solve useful problems and deepen my understanding. I test ideas, look at the results, and improve as I learn.
